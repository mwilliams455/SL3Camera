# Project roadmap

## 1. Base still-image rendering — active research stage

Recover and validate the protected implementation, establish one defined base photographic configuration without downloadable Looks, and reproduce it offline. Keep numerical reconstruction distinct from comparisons against genuine SL3-P photographs. Do not substitute an M9/M10-R/M11 renderer or L-Log mathematics for unknown SL3-P processing.

Only after this gate should Photon integration become active. Preserve DNG data, dependable capture and image quality. Keep source sensor/lens calibration separate from the device-independent target.

## 2. Optional Leica Looks — deferred

Inspect user-supplied assets locally. Establish format, input/output colour representation, insertion order and intensity behaviour before applying them. Exact bypass must return the validated base render. Preview and saved-image parity require equivalent inputs as well as the same transform. Do not assume every asset is a conventional sRGB .cube or a post-render blend. Do not publish the original assets.

## 3. Video — deferred

Start with controlled frame-sequence colour/temporal tests, then integrate live preview and recording. Treat recorded-look and log-plus-viewing-LUT modes explicitly. Validate sustained frame pacing, exposure/white-balance stability, audio sync and supported codecs independently. Published L-Log reference maths are a building block, not a complete port.

## Separate track: autofocus and recognition

Map resources and caller behaviour if evidence becomes available. A colour renderer does not inherit Leica autofocus performance. Device-supported autofocus remains a separate integration concern.

## Research discipline

No introduced HDR, no Cobalt dependency, no visible quality sacrifice for speed without explicit agreement. Preserve prior negative results and distinguish observed facts, inferences and untested hypotheses. Never treat directory offsets as RAM addresses or marker hits as decoded assets without validation.
